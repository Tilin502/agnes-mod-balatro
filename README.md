# agnes-mod-balatro
Mod que agrega una nueva carta y etiqueta que funcionan en conjunto al juego de Balatro

Para jugar con **Agnes Tachuelas**, sigue estos  pasos:

1. Asegúrate de tener instalado **Steamodded** y **Lovely** en tu juego.
2. Descarga este mod haciendo clic en el botón verde **Code** (arriba a la derecha) y seleccionando **Download ZIP**.
3. Descomprime el archivo `.zip` para obtener la carpeta `agnes_mod`.
4. Mueve la carpeta `agnes_mod` a la ruta de mods de tu sistema operativo:

 ##  En Linux (Steam Deck / Escritorio)
`~/.local/share/Steam/steamapps/compatdata/237980/pfx/drive_c/users/steamuser/AppData/Roaming/Balatro/Mods/`

##  En Windows
Presiona `Win + R`, escribe `%appdata%/Balatro/Mods` y presiona Enter.

5. ¡Inicia *Balatro* y activa el mod en el menú!
